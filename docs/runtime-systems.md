# 子代理、技能与后台任务

本实现移植 dsh 的运行时分工，使用 Rust 的 `SessionDriver`、JSONL 日志和现有权限桥接；不需要 Cordis 插件运行时。

## 子代理

- `spawn_agent` 创建独立历史；`fork_agent` 复制父会话已闭合轮次，避免继承未完成的工具调用。
- 默认后台返回 `childId` 与已准入的 `messageId`。`run_in_background: false` 等待子代理结果；`wait_agent` 提供独立、有时限的等待。
- 子代理继承父会话目录、权限、模型选择和工具范围；可覆写模型、推理强度、角色提示及进一步缩小工具集合。未知工具或扩大父代理工具范围会被拒绝。
- 会话头中的 `subagent` 描述符记录角色、模型、深度与创建方式，`parent_session` 记录谱系。普通用户分支与子代理明确区分。
- `send_message` 仅允许直接父子通信；`interrupt_agent` 可控制后代。运行时消息先记录 `agent-inbox`，在模型步骤边界记录 `agent-delivery`；后者同时是模型历史投影与领取记录，重复恢复不会再次领取。
- 停止保留会话；后续消息可继续。完成通知进入父代理的同一个收件箱；空闲父代理可被有预算地唤醒。
- 子代理加入父工作区账本。控制台可打开其执行轨迹、处理审批、从父会话发消息或停止；子代理输入栏为只读。删除父会话会清理其后代；仍在执行的后代阻止删除。

## 技能

发现顺序由高到低：项目 `.denia/skills`、项目 `.dsh/skills`、项目 `.agents/skills`、自定义目录、denia 数据目录 `skills`、用户 `.agents/skills`，最后是内置 bundled 技能。项目根取最近的 `.git` 祖先，找不到则取会话目录。内置 `skill-creator` 用于创建或更新高质量 skill；同名项目或用户技能可以覆盖它。

兼容 `<name>/SKILL.md` 与 `<name>.md`。名称使用小写 kebab-case；YAML frontmatter 支持 `name`、`description`、`disable-model-invocation`、`user-invocable`。同名技能由更高优先级目录覆盖。元数据错误明确返回错误。

`skill` 的 `list` 操作发现目录，`load` 操作读取正文与 `resourceBase`；`resource` 操作按名称和相对路径读取技能目录内的 UTF-8 参考文件，拒绝越界路径。模型目录仅包含允许模型调用的技能；控制台不提供技能选择或预览栏；模型按任务需要发现、加载技能。服务端显式调用接口仍保留调用策略验证。技能不会扩大文件或命令权限。

目录扫描与文件读取在阻塞线程池运行，摘要按文件属性缓存；每步比较目录上下文，只在内容变化时注入。支持外部编辑后下一步重新发现。技能正文不进入初始目录。

## 后台任务

`job_start` 或 `bash` 的 `run_in_background: true` 启动后台命令。`job_list`、`job_output`、`job_kill` 管理当前会话拥有的任务，其他会话不能读取或停止。

标准输出与错误输出并行排空，保留有限尾部，防止大输出塞满管道。记录总数有全局上限，活动任务还受每会话并发上限约束。运行中 `job_output` 返回增量，结束后重复读取返回保留的完整结果；等待超时仅结束等待。控制台预览不消耗模型输出游标或通知状态。Windows 停止使用进程树终止，再等待直接子进程回收。

后台任务记录属于当前服务进程；服务重启后不会恢复操作系统进程。已领取的工具结果保留在会话日志中。完成通知先由注册表结算，再进入会话收件箱。

## 配置与验证

设置页“代理与任务”对应 validated `runtime` 命名空间：子代理并发、委派深度、后台任务并发与保留数、输出字节数、等待与执行超时、待收消息数、自动唤醒预算、自定义技能目录。保存使用 revision 并发控制。

服务端测试覆盖谱系与权限边界、冷恢复去重、继续执行、取消、准入失败与清理，以及 HTTP → 模型工具调用 → 子代理 / 后台 bash / 结果读取 / 技能加载的完整链路。

本次实现的是 dsh 的原生进程内能力。ACP、Codex、Claude Code、DSH SDK 等可选外部传输及 Cordis 提供方插件不是当前 denia 已注册的能力；请求未支持的工具参数会明确拒绝。浏览器视觉验收由用户在开发端口 3601 完成。
